
MIND.OS

COMO COLOCAR AS MÚSICAS:

1. Abra a pasta /songs
2. Coloque músicas .mp3 nela
3. Renomeie exatamente assim:

focused.mp3
chaotic.mp3
dreamy.mp3
melancholic.mp3
confident.mp3

Exemplo:
focused.mp3 -> música clássica
chaotic.mp3 -> Lana Del Rey
dreamy.mp3 -> synthwave
etc.

Depois basta abrir o index.html.
